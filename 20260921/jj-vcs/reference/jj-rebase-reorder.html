Rebase & reorder cheat sheet

The compressed essence of Lesson 3.

Git → jj

Git 
git rebase -i (reorder)
git rebase -i (drop)
git cherry-pick
jj 
jj rebase -r <rev> -A|-B <dest>
jj abandon <rev>
jj rebase -r <rev> -o <dest>

jj rebase flags (0.45.x)

# which commits to move
-r, --revision   <rev>         just that revision (no descendants)
-s, --source     <rev>         that revision AND its descendants
-b, --branch     <rev>         a whole branch, relative to dest

# where to move them (pick one)
-o, --onto       <dest>        rebase onto <dest>
-A, --insert-after  <dest>     place directly after <dest>
-B, --insert-before <dest>     place directly before <dest>

Note: there is no -d/--destination flag in 0.45.x — the destination is -o, -A, or -B.

The moves

jj rebase -r @--- -A @-    # move bottom commit to top (reorder)
jj rebase -s @-- -o main   # rebase a stack onto updated main
jj abandon @--             # drop the grandparent commit

Revset shorthand

@      working-copy commit
@-     parent
@--    grandparent
@---   great-grandparent
description("add a.txt")   # select by message (quote spaces)

Always true

  • Rewriting or moving a commit auto-rebases its descendants.
  • Change IDs survive the move; commit IDs change.
  • jj undo reverses any of this — experiment freely.
