Rewriting cheat sheet

The compressed essence of Lesson 2.

Git → jj (rewriting)

Git 
git commit --amend
git rebase -i (reword)
git reflog + reset
git reset --hard
jj 
jj squash
jj describe -r <rev>
jj undo / jj redo
jj restore

The verbs

jj squash                 # fold @ into parent (the "amend")
jj squash <path>           # move one file's changes into parent
jj squash -i               # choose hunks to move (git add -p)
jj describe -r <rev> -m …  # reword any commit
jj undo                    # rewind last operation
jj redo                    # move forward again
jj op log                  # browse the operation log

The model to remember

  • Change ID survives rewriting; commit ID changes. Amend = same change, new content.
  • Rewriting any commit auto-rebases its descendants ("Rebased N descendant commits.").
  • There is no jj amend — jj suggests jj squash instead.
  • The operation log (not a reflog) powers undo — it's first-class and navigable.

Revset shorthand used so far

@     working-copy commit
@-    parent of @
@--   grandparent of @
