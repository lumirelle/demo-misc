The compressed essence of Lesson 4 — moving changes between commits.

Git → jj

Git 
git rebase -i (fixup)
git cherry-pick
git add -p
jj 
jj squash --from X --into Y
jj squash --from X --into Y <path>
jj split -i

The command

jj squash --from <src> --into <dst>           # move ALL of src into dst
jj squash --from <src> --into <dst> <path>   # move one file's changes
  • With a path: only that file moves; the source keeps the rest. No prompt.
  • Without a path: everything moves; if the source is emptied, it's abandoned and jj asks you to combine the two commit messages.

Revset levels in a stack

@      working copy
@-     = B   (one up from root's child)
@--    = A   (the earlier commit)
@---   = root  (immutable — don't squash into it)

Reverse direction (coming in Lesson 5)

jj split            # separate @ into two, interactively
jj split -i         # choose hunks (git add -p)
jj split <path>     # keep <path> here, move the rest up
