# Prior knowledge: comfortable daily Git user

The user disclosed being a comfortable daily Git user: branches, commits, merge/PRs, and occasional rebases, but they avoid deep history surgery (reflog recovery, interactive rebase, submodules). Their mission is to replace Git day-to-day with jj.

Implications: lessons should map jj concepts onto already-understood Git concepts (index, commit, branch, rebase) rather than re-explain version control from scratch. Deep Git surgery is *not* prior knowledge, so jj's equivalents (operation log, automatic rebase, conflict propagation) still need real teaching rather than a one-line analogy.
