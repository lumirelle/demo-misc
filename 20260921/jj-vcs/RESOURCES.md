# Jujutsu (jj) Resources

## Knowledge

- [Official documentation (latest)](https://docs.jj-vcs.dev/latest/)
  The authoritative reference for jj: tutorial, install & setup, config, revsets, git-comparison, FAQ, glossary. Use for: verifying any command, flag, or concept before teaching it.
- [Official tutorial and bird's-eye view](https://docs.jj-vcs.dev/latest/tutorial/)
  Short orientation written for people who already know Git. Use for: first mental-model mapping from Git to jj.
- [Git comparison (incl. jj↔git command table)](https://docs.jj-vcs.dev/latest/git-comparison/)
  Direct mapping between jj and git commands, plus the "no index" rationale. Use for: translating a Git habit into jj.
- [Steve Klabnik's Jujutsu Tutorial](https://steveklabnik.github.io/jujutsu-tutorial/)
  Widely-recommended, deeper tutorial. Explains the *why* behind jj's model, not just the commands. Use for: the conceptual "working copy is a commit" framing and motivations.
- [GitHub: jj-vcs/jj](https://github.com/jj-vcs/jj)
  Source repo, README, install instructions, roadmap, release notes. Use for: install problems and tracking which features are stable vs. experimental.
- [LWN: "Jujutsu: a new, Git-compatible version control system"](https://lwn.net/Articles/958468/)
  Independent, high-quality overview of jj's design. Use for: a second, outside perspective on the model.
- [Chris Krycho: "jj init" essay](https://v5.chriskrycho.com/essays/jj-init/)
  A thoughtful practitioner's account of adopting jj from a deep-Git background. Use for: realistic expectations and workflow advice.

## Wisdom (Communities)

- [jj Discord](https://github.com/jj-vcs/jj) (invite linked from the README badge)
  Active community of jj users plus the core developers. Use for: "how do I do X that I used to do in Git" workflow questions.
- [GitHub Discussions: jj-vcs/jj](https://github.com/jj-vcs/jj/discussions)
  Slower-moving, searchable Q&A and design rationale. Use for: longer-form questions and feature discussion.
- IRC: `#jujutsu` on Libera Chat
  Bridged with the Discord. Use for: quick real-time questions.

## Gaps

- No dedicated hands-on exercise book found yet (the official tutorial + Klabnik's tutorial are the closest). Worth filling with our own interactive lessons as the workspace grows.
