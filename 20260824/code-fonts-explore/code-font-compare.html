编程字体探索 · 为 Merriweather UI 找同温代码字

昨天从 6 个 UI 字体里选了 Merriweather（屏读衬线、厚实、暖）。代码字体锁定 annotation mono + maple mono cn——都是 humanist、偏暖、带连字、有性格。这页找"同温"的编程字体：暖色 / humanist / 有性格但不喧宾夺主 / 屏读优先。六个字体在 9pt 下渲染同一段 TypeScript，看谁和 Merriweather 坐在一起最和谐。

观察要点

  • 温度梯度（从冷到暖）：Inconsolata（经典 humanist，中性偏暖）→ Spline Sans Mono（humanist，温和）→ Monaspace Radon（humanist 带衬线味，最暖的 Monaspace）→ Maple Mono（圆润、亲和、暖）→ Recursive（Casual 轴拉满，最松弛）→ Commit Mono（Stephen Nixon 手笔，暖且有骨气）。你现在的 Maple Mono 已经在暖端，往下找"同温或更暖"的伙伴。
  • 0 / O / o：代码字体的生死线。Commit Mono 和 Radon 的零带斜线（slash），最易辨；Maple Mono 零带竖线点（dotted zero），圆润可爱；Recursive 零偏窄椭圆，靠形状区分；Inconsolata 零带点，经典做法；Spline 零带斜线。六个都能过 0/O 关，但风格不同。
  • 1 / l / I：Commit Mono 的 l 带底弯钩，和 1 区分最清楚；Radon 的 l 是直竖带衬线底脚，有人文气；Maple Mono 的 l 带底钩，圆润；Recursive Casual 模式下 l 带手写味弯钩；Inconsolata 的 l 带顶底衬线，经典；Spline 的 l 简洁直竖。
  • g / a：Commit Mono 单层 a + 单层 g（现代、干净）；Radon 双层 g 带衬线味（和 Merriweather 的 g 呼应！）；Maple Mono 单层 a + 圆润 g；Recursive Casual 下 g 带手写味；Inconsolata 单层 g；Spline 单层 a + 单层 g。Radon 是唯一双层 g——这是它和 Merriweather 衬线 UI 最搭的原因。
  • 连字 => ≠ ::：Maple Mono、Commit Mono、Radon、Recursive 都有连字；Inconsolata 和 Spline 无连字（更传统）。点右上角"连字 ON/OFF"切换对比。连字是"有性格"的标志，但传统派认为代码不该连字——看你站哪边。
  • 和 Merriweather 的配对：Merriweather 是厚实屏读衬线，配代码字要"暖但不抢戏"。Radon 是最佳配对——它本身带衬线味（双层 g、人文脚），和 Merriweather 同属"有温度的传统派"。Commit Mono 次之，骨气更足、更现代，适合想要"衬线 UI + 现代代码"的张力感。Maple Mono（你现在的选择）圆润亲和，和 Merriweather 的厚实感互补，已经很搭。
  • 和 annotation mono 的关系：Commit Mono 和 annotation mono 都出自 Stephen Nixon（Arrowtype）之手，同属"暖 humanist"血脉。如果你喜欢 annotation mono 的性格，Commit Mono 是最直接的免费同门——可以当 annotation mono 的开源替代或备选。
  • 9pt 可读性：Inconsolata 和 Spline 在 9pt 最稳（笔画均匀、x-height 高）；Commit Mono 和 Radon 紧随其后；Maple Mono 9pt 下圆润字形偶尔偏糊（尤其 o/a 收口）；Recursive Casual 模式 9pt 下手写味会加重，建议 CASL 调到 0.5 左右更稳。
