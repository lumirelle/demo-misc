更衬线的编程字体 · 比 Recursive 0.5 多一点衬线

你定了 Recursive @ CASL 0.5（humanist、可控、不花），现在要"更衬线一点"。方向是：保留 humanist 骨架 + 可控，加上衬线脚 / 双层 g。主角是 Monaspace Xenon——Radon 的 slab serif 同族兄弟，有衬线但没人文手写味，且可变（wght 200–800）。下面五个字体在 9pt 下配 Merriweather 正文同框对比。

Recursive@0.5 Xenon Radon Cutive Nova

观察要点

  • 衬线谱系：Recursive@0.5 无衬线（humanist sans-mono）；Xenon 是 slab serif（矩形衬线脚，块状）；Radon 是 humanist 带衬线味（脚更柔和、带人文气）；Cutive Mono 是打字机 slab serif（Courier 血统）；Nova Mono 是装饰性 slab。从"无衬线"到"重 slab"的梯度：Recursive → Radon → Xenon → Cutive。
  • 为什么 Xenon 是主角：Xenon 和 Radon 是同族（Monaspace 五兄弟），共享 humanist 骨架和等宽 metrics——但 Xenon 用 slab serif 脚替代了 Radon 的手写味。它是"Radon 去掉手写感、换成正经衬线"的版本。如果你嫌 Radon 偏手写，Xenon 就是答案。而且它可变（wght/wdth/slnt），和 Recursive 一样能调。
  • g 的故事：Recursive 单层 g；Xenon 双层 g（slab 风格，和 Merriweather 的 g 呼应！）；Radon 双层 g 带人文脚；Cutive 双层 g 打字机风；Nova 双层 g 装饰。Xenon 和 Radon 的双层 g 是它们和 Merriweather 衬线 UI 搭配的关键——同属"有衬线传统"。
  • 和 Merriweather 的配对：Merriweather 是屏读衬线、笔画厚实、有 bracketed serif（带弧度过渡的衬线）。Xenon 的 slab 是矩形无弧度的——和 Merriweather 的 bracketed serif 是不同衬线亚类，但都是"正经衬线"，搭在一起有"同族不同支"的和谐。字重调到 450–500，厚实感呼应。
  • Xenon vs Recursive 怎么选：要"humanist + 可控 + 无衬线、最现代"选 Recursive@0.5；要"humanist + 可控 + 有衬线、和 Merriweather 同属衬线传统"选 Xenon。两者都可变、都暖、都 humanist——差别只在"有没有衬线脚"。
  • Cutive / Nova 的定位：Cutive Mono 是打字机 slab，气质偏复古/文学，适合想要"代码像手稿"的氛围，但 9pt 下笔画偏粗、占宽大；Nova Mono 是装饰 slab，只有一个字重、气质强，适合点缀不适合正文代码。两者都不可变，作为"更传统的 slab"参照。
  • 没出现的 Iosevka Slab：理论上 Iosevka Slab 是"超可变 slab serif mono"的理想答案（wght/wdth/slnt 全可调），但它的 release 包 100MB+、不在 Fontsource，无法直接 CDN 引用。如果你愿意本地安装，Iosevka Slab 是 Recursive 的"全衬线版"平替——可定制程度甚至超过 Recursive。
