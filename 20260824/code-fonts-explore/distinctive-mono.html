独特风格编程字体调研

不再围绕 Merriweather 搭配，专看"性格光谱"的极端——那些有强烈辨识度、一眼能认出的编程字体。按性格类型分组：草书斜体 / 宽体工业 / 几何怪趣 / 复古 CRT / 像素 lo-fi / 数学符号 / 俏皮。每个字体配一段带斜体注释的代码，展示它最 distinctive 的特征。

性格光谱笔记

  • 草书斜体 · Victor Mono：免费字体里最 distinctive 的斜体——italic 是真正的手写草书（cursive），不是普通倾斜。配 italic 主题（如 One Dark italic）效果拉满。它的正体是 humanist sans-mono，但斜体才是灵魂。可变字体（wght 100–700）。
  • 宽体工业 · Martian Mono：字宽明显比常规 mono 宽（每个字符占更多横向空间），块状、建筑感、工业风。由 Mooniak 设计。适合想要"代码像蓝图"的氛围。可变（wght 100–800）。缺点是同样字号下每行能放的字符少。
  • 几何怪趣 · Kode Mono：Indian Type Foundry 出品，几何骨架但带圆润收尾，有"设计感"不像传统 mono。可变（wght 100–700）。性格比 JetBrains Mono 强，比 Victor Mono 内敛。
  • 复古俏皮 · Space Mono：Colophon Foundry 出品，复古印刷感，g 和 a 是单层、带 quirky 收尾。Google Fonts 上最有"设计字体"气质的 mono。只有 400/700 两档，不可变。
  • CRT 终端 · Share Tech Mono：纯终端/CRT 复古风，像老式示波器或 DOS 屏幕。只有一个字重。适合想要"黑客电影"氛围的展示场景，正文代码偏累。
  • 像素 lo-fi · Departure Mono：像素/位图美学，lo-fi techy vibe。字形带像素锯齿感，适合 retro-cyberpunk 场景。只有一个字重，小字号下最有味道。
  • 数学符号 · JuliaMono：为 Julia 语言设计，最大特色是内置海量 Unicode 数学/技术符号（∑ ∫ √ λ ⊗ ∈ ⊂ …），在代码里直接写数学公式不缺字。正体是干净 humanist。如果你写 LaTeX/Julia/数学密集代码，无可替代。
  • 俏皮亲和 · Comic Mono：Comic Sans 的等宽版，圆润、手写、不严肃。适合想要"代码不吓人"的教学/演示场景。正经项目慎用——但它的"不正经"本身就是一种风格声明。
  • 没出现的付费字体：Operator Mono（草书斜体鼻祖，付费）、Dank Mono（草书斜体，免费但不在 CDN）、Berkeley Mono（quiet luxury，付费）、PragmataPro（极致紧凑，付费）、MonoLisa（可读性优先，付费）。如果你愿意付费，Operator Mono 和 Berkeley Mono 是"有性格的工作马"的两个极端。
