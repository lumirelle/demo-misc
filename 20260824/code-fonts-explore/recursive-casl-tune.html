代码字体的温度

A typeface for code should sit beside the body text without friction. Merriweather carries prose with a warm, sturdy hand — its strokes are even, its x-height generous. A monospace that shares that warmth disappears into the page.

代码字体的温度，应该和正文字体走在同一侧。配一个同暖的等宽字，代码块就自然嵌入页面；配一个冷峻的字，每个 code block 都像外来物。

决策笔记

  • 为什么 Radon 偏手写：Radon 的双层 g 和人文脚（serif-like feet）是刻在字形里的——这是它和 Merriweather 衬线气质呼应的原因，也是"偏手写"的来源。它没法调，要么接受这个性格，要么换。
  • Recursive 的 CASL 轴在调什么：不是调"暖度"（humanist 骨架始终在），而是调笔画的"松弛度"。CASL 0 时笔画均匀、收笔利落，接近 Linear Mono；CASL 1 时笔画带手写弯钩、收笔圆润，是 Casual Mono。你说的"不那么花"在 CASL 1 下成立，调到 0.3–0.5 会更克制。
  • 甜点推荐 0.5：Stephen Nixon（Recursive 设计师）本人推荐代码用 CASL 0.5 + wght 450。这个点 humanist 气质还在、但衬线脚的跳跃感消失，和厚实衬线 UI 字（Merriweather）同框最稳。如果你觉得 0.5 还是偏花，试 0.3。
  • Radon vs Recursive 怎么选：要"传统衬线味、和 Merriweather 同属一脉"选 Radon（接受它的手写感）；要"humanist 气质在、但更现代克制、可微调"选 Recursive。两者都是暖 humanist，和 Merriweather 都搭——差别在"传统 vs 现代"的张力。
  • 和 annotation mono 的关系：你现在的 annotation mono 和 Recursive 同属"暖 humanist 可变字体"路线。Recursive 可以当 annotation mono 的开源替代——CASL 调到 0.3 左右、wght 450，气质非常接近，且免费可商用。
